提 issue 之前

先看一眼 已有的 issue —— 很多问题已经被提过并解决了。 搜一下关键词可能更快。

报 bug 请附上这些

  • 你的 Chrome 版本（chrome://version 里能看到）
  • Shotly 版本（扩展详情页左上角）
  • 出问题的网址
  • 截图 —— 如果是页面显示不对，直接把出问题的画面截下来
  • 复现步骤：做了什么操作、期望看到什么、实际看到什么

常见问题

整页截图在某些网站上不完整

先看是不是页面太长了。Shotly 的上限是 min(50 000, ⌊65 535 / DPR⌋) CSS 像素 （页面上会有提示）。另一个常见原因是页面上有 position: fixed 的悬浮元素 （吸顶导航、悬浮按钮），它们在拼接时会重复出现 —— 这是已知限制。

区域截图选不了某些区域

最小 100×100 像素。另外如果选区框在 iframe 内部，浏览器不允许跨 iframe 操作， 这是浏览器的限制。

截图没出现在历史列表里

历史库最多存 50 条，超出自动淘汰最旧的。如果刚截图完就找不见， 先看看是不是之前已经存了 50 条。

PDF 导出打不开

请把问题连同导出的 PDF 一起作为 issue 附件上传。

怎么确认它真的不上传截图

Chrome 开发者工具 → Network 面板，跑一次截图，看有没有任何第三方请求。 Shotly 的测试套件里就有一条 E2E 专门做这件事（跑完整截图流程并拦截所有请求）。 源码在 https://github.com/weihongdago/shotly。
