Chrome extension

Shotly

Whole-page screenshots for Chrome — stitched at full device resolution, exported as PNG / JPG / PDF, and never uploaded anywhere.

View source on GitHub Support Privacy policy

Retina-correct

The stitch canvas is sized in device pixels, so a 1280 px page on a 2× display exports a 2560 px image — never a downsampled one.

Private by construction

No accounts, no telemetry, no third-party requests. Screenshots live in your browser's IndexedDB and nowhere else.

Handles the hard pages

Lazy images, fixed headers, cross-origin embeds, web fonts and 50 000 px documents — all covered by five verified scenarios.

What it does

  • Whole-page capture with a live progress bar
  • Region capture — drag a rectangle, get just that
  • Export to PNG, JPG or PDF (and copy straight to the clipboard)
  • Local history (50 entries, LRU) so you can re-download yesterday's shot
  • Light and dark UI

Install

git clone https://github.com/weihongdago/shotly.git
cd shotly
pnpm install
pnpm build      # → .output/chrome-mv3
pnpm zip        # → .output/shotly-0.1.0-chrome.zip

Then load it: chrome://extensions/ → enable Developer mode → Load unpacked → pick shotly/.output/chrome-mv3.
